Red Hat | トレーニングスケジュール

Red Hat 公式トレーニング（日本向け）の開催予定を一覧で掲載しています。

  • コースコードのリンクをクリックすると、そのトレーニングコースの概要ページにアクセスできます。
  • Class ID（旧 Offering ID）のリンクをクリックすると、そのトレーニングセッションの申し込み用ページに移動します。

ご注意（リンク先・データ）

一部のクラスでは、満席などの理由により、Class ID（旧 Offering ID）のリンクをクリックしてもお申し込み用ページが表示されない場合があります。 また、本ページの表と docs/data_2026.csv・docs/data_2027.csv（GitHub Raw）の内容が食い違う場合は、data_YYYY.csv 側の情報を正として参照してください。ブラウザや CDN のキャッシュの影響で、本ページに古い情報が残っていることがあります。

2026年1月より、トレーニングの購入は年間サブスクリプション「Red Hat Learning Subscription（RHLS）」が基本です。詳細は こちらをご覧ください。
