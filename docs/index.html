Red Hat | トレーニングスケジュール

このサイトは、Red Hat Learning Subscription Premium 及び Course 利用者様向けの、ライブバーチャルクラス（LVC）の予定を一元的に確認するためのサイトです。

📢 お知らせ （掲載日時: 2026/10/19 15:27 JST）

  • 2027年のクラス開講予定の掲載を開始しました。2026年分と続けて一覧で確認できます。
  • 開講クラスの Raw データを年度別に分割しました。 data_2026.csv／ data_2027.csv
  • 各コースの開講状況がひと目でわかる「開催頻度グラフ」を追加しました。 開催が多いコース・珍しいコースを棒グラフで比較でき、製品カテゴリでの絞り込みにも対応しています。

📖 このサイトの使い方

  • 座席の確保について: クラスのための座席確保は、このページからはできません。手順は下の参考動画（YouTube）で解説していますので、ご覧ください。
  • 活用のポイント: 開催予定回を長期的に把握できます。学習計画や受講回の検討にご活用ください。
  • コースコードのリンクをクリックすると、そのトレーニングコースの概要ページにアクセスできます。
  • Class ID（旧 Offering ID）のリンクをクリックすると、Red Hat LMS でその Class ID を検索します（現在リンク切れのため修正中）。

⚠️ ご注意

満席などで、Class ID のリンク先（申し込みページ）が開けないことがあります。
表示が古い場合は、GitHub 上の CSVを正としてご確認ください。

2026年1月より、トレーニングの購入は年間サブスクリプション「Red Hat Learning Subscription（RHLS）」が基本です。詳細は こちらをご覧ください。

参考動画（YouTube）

RHLS Premium / Course 両ユーザー様は、本サイトでご都合が合うクラスを見つけたら、以下の手順で席を確保します。

以下のプレーヤーからページ内で再生できます（ YouTube で開く）。

読み込み中…

開催のある日をクリックすると、その日のクラスを表示します。

どのコースがどれくらい開催されるか

棒をクリックすると、そのコースの開催日程を「コースから探す」で表示します。「レア」は集計範囲で 1 回しか開催されないコースです。

月 × コース（開催数ヒートマップ）

すべてのクラスを表で確認できます。製品カテゴリ・月での絞り込みができます。
